YOU MUST BE AUTONOMOUS. READ THE AGENTS.md FILE AND REMEMBER TO USE IT TO LEARN. IF YOU ARE THE CODEX_CLI WRITING IN THIS FILE IS ENCOURAGED BUT WITH GREAT POWER COMES GREAT RESPONSIBILITY.

## Création de sous-projets et exécution déléguée

Lire [memory-bank/project-init-protocol.md](memory-bank/project-init-protocol.md)
avant de créer un sous-projet. Utiliser les modèles dans common/templates et
les scripts dans scripts/project-init. Les décisions actives couvrent le choix
du parent en premier, l'automatisation des règles, le socle complet avec no-op
explicites, Rush/pnpm et le langage informatif. Les no-op demandés pour les étapes
non définies sont autorisés et doivent rester identifiés comme non configurés.
